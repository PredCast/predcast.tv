ACCESSIBILITY RULES

Focus: outline 2px #E8001D, offset 2px on :focus-visible — every button, link, input, nav item. Status never by colour alone: glyph + word (✓ OK, ✕ FAIL, ▲ LOW, S1–S5 label, CRITICAL / WARNING). Numbers: font-variant-numeric: tabular-nums everywhere a value can change. Icon-only buttons carry aria-label; decorative SVG aria-hidden; live regions: health pill role=status, alerts role=alert.
